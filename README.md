# BookNest – Online Book Store

## About the Project
BookNest is a simple online bookstore built using React. It allows users to explore books, browse categories, view book descriptions, and add books to their shopping cart.

## Features
- Browse all available books.
- Filter books by category.
- View book descriptions using the Read More button.
- Add books to the shopping cart.
- View selected books in the Cart page.
- Contact form with basic validation.
- Navigation between different pages.

## Installation and Setup

	1.	Clone the repository:
git clone https://github.com/booknestgit/BookNest.git
	2.	Navigate to the project folder:
cd BookNest
	3.	Install dependencies:
npm install
	4.	Start the development server:
npm start
